The Patron API flow follows the complete food order process from the perspective of the patron.

## 1. Start browsing (Click on a food category tab)

### Request

The client sends an HTTP request, filtering results to dishes belonging to the specific category, such as Main Course, and limiting information to dish name and description.

```shellscript
curl -X 'GET' \
  'https://bookish-potato-967rw54rwqwwfx5qq-80.app.github.dev/dishes?order=asc&fields=name%7Cdescription&filter=category.eq~Main%20Course&limit=30&offset=0' \
  -H 'accept: application/json'
```

### Response

If the request was successful, the server responds with a `200` status code with the response body containing the list of dishes in the specified category and their relevant details.

```json
{
  "results": [
    {
      "id": "6a3420277b22606bb2fa511f",
      "name": "Spaghetti Carbonara",
      "description": "Pasta cooked with eggs, cheese, pancetta, and black pepper for a creamy, savory dish."
    },
    {
      "id": "6a3420277b22606bb2fa5126",
      "name": "Lasagna alla Bolognese",
      "description": "Layers of pasta, beef ragu, and béchamel sauce baked to perfection."
    },
    {
      "id": "6a3420277b22606bb2fa512d",
      "name": "Margherita Pizza",
      "description": "A classic pizza topped with fresh tomato sauce, mozzarella cheese, and basil leaves."
    },
```

## 2. Check ingredient quantities

### Request

The client sends an HTTP request, filtering the response to only include results with ingredients available, including the ingredient quantities.

```shellscript
curl -X 'GET' \
  'https://bookish-potato-967rw54rwqwwfx5qq-80.app.github.dev/ingredients?sort=name&order=asc&fields=name%7Cin_stock_qty&filter=in_stock_qty.gte~1&limit=10&offset=0' \
  -H 'accept: application/json'
```

### Response

If the request was successful, the server responds with a `200` status code with the response body containing available ingredients and their quantities.

```json
{
  "results": [
    {
      "id": "6a3420277b22606bb2fa50f7",
      "name": "Balsamic Vinegar",
      "in_stock_qty": 37
    },
    {
      "id": "6a3420277b22606bb2fa50e6",
      "name": "Beef Broth",
      "in_stock_qty": 64
    },
    {
      "id": "6a3420277b22606bb2fa50cc",
      "name": "Bell Peppers",
      "in_stock_qty": 6
    },
```

## 3. View dish details

### Request

The client sends an HTTP request, returning details for the dish that the user selects.

```shellscript
curl -X 'GET' \
  'https://bookish-potato-967rw54rwqwwfx5qq-80.app.github.dev/dishes/6a3420277b22606bb2fa512d?fields=name%7Cprice%7Cimage_name%7Cdescription' \
  -H 'accept: application/json'
```

### Response

If the request was successful, the server responds with a `200` status code with the response body containing the details for the relevant dish, including its image, price, and description.

```json
{
  "id": "6a3420277b22606bb2fa512d",
  "name": "Margherita Pizza",
  "description": "A classic pizza topped with fresh tomato sauce, mozzarella cheese, and basil leaves.",
  "price": 799,
  "image_name": "margherita_pizza"
}
```

## 4. Add dishes and view the cart

The user continues to view dishes and add them to the cart. The client keeps track of which dishes have been added to the cart.

## 5. Place an order

### Request

The client sends an HTTP request, retrieving the dishes the user selected and including them in the request body.

```shellscript
curl -X 'POST' \
  'https://bookish-potato-967rw54rwqwwfx5qq-80.app.github.dev/orders' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "name": "Caterina",
  "table_number": 5,
  "dish_ids": [
    "6a3420277b22606bb2fa512d",
    "6a3420277b22606bb2fa5133",
    "6a3420277b22606bb2fa5155"
  ],
  "special_requests": "No meat.",
  "scheduled at": null
}'
```

### Response

If the request was successful, the server responds with a `201 Created` status code with the response body containing the order details, including the patron name, dishes ordered, and special requests.

```json
{
  "id": "6a7f5ed9e22205fa2fb219a8",
  "created_at": "2026-08-14T18:30:49.425Z",
  "updated_at": "2026-08-14T18:30:49.425Z",
  "scheduled_at": null,
  "table_number": 5,
  "status": "Received",
  "priority": 3,
  "dish_ids": [
    "6a3420277b22606bb2fa512d",
    "6a3420277b22606bb2fa5133",
    "6a3420277b22606bb2fa5155"
  ],
  "special_requests": "No meat."
}
```

## 6. Order confirmation

### Request

The client sends an HTTP request, retrieving the details for the order.

```shellscript
curl -X 'GET' \
  'https://bookish-potato-967rw54rwqwwfx5qq-80.app.github.dev/orders/6a7f5ed9e22205fa2fb219a8?fields=status' \
  -H 'accept: application/json'
```

### Response

If the request was successful, the server responds with a `200` status code with the response body containing the order ID and the status.

```json
{
  "id": "6a7f5ed9e22205fa2fb219a8",
  "status": "Received"
}
```
